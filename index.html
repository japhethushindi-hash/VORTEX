CAPSTONE PROJECT

Build a Study Planner in Python

Create a command-line program that lets a learner add study tasks, list them, mark them complete, and save them to a file. Build one feature at a time.

Milestone 1

Store tasks in a Python list and display them with a loop.

Milestone 2

Use functions and input validation to add and complete tasks.

Milestone 3

Save and load tasks using JSON and handle file errors.

Success criteria: invalid choices do not crash the program, tasks survive restarting the app, and a README explains how to run it.

Freelance safely

Start with small, clearly scoped projects and communicate professionally.

  • Agree scope and milestones in writing
  • Use a safe payment arrangement
  • Never pay a recruiter to get a job
